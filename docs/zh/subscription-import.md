# 导入外部机场订阅

升级代码后，先在运行 Xboard 的环境中执行数据库迁移，再重启应用进程：

```sh
php artisan migrate --force
```

进入管理后台的节点页面，点击右下角“导入机场订阅”：

1. 粘贴机场的 HTTP／HTTPS 订阅链接，点击“获取并预览”。
2. 核对解析结果和跳过原因，勾选需要导入的节点。
3. 选择用户套餐所属的权限组，设置是否显示，然后点击“导入所选节点”。
4. 关闭窗口后，节点列表会刷新。新节点带有“外部订阅”标签。

支持明文节点链接、Base64／URL-safe Base64 节点订阅，以及包含 `proxies` 的 Clash YAML／JSON。首版支持 Shadowsocks（包括 SS2022）、VMess AEAD、VLESS、Trojan、Hysteria2 和 AnyTLS；支持常见 TCP、WebSocket、gRPC、HTTP/2 和 VLESS／Trojan Reality 配置。旧版 VMess、自定义 ALPN、TUIC、SSR、XHTTP、端口跳跃等暂不支持，会在预览中报告跳过原因。Clash 配置中的规则和代理组不会导入。

预览有效期为 10 分钟，仅创建预览的管理员可使用。可导入不超过 1000 个节点，订阅下载上限为 2 MB。订阅源必须使用公网地址，重定向目的地址也会检查；节点的连接地址不会由平台主动探测。

## 再次导入

目前通过手动再次导入更新，尚无定时同步。使用同一完整订阅链接导入时，以节点协议、名称、地址和端口识别已有节点，更新认证信息、连接参数、权限组和显示设置，保留已有标签、排序和倍率。只处理选中的节点，不自动删除源中消失的节点；名称、地址、端口或订阅链接发生变化时会新增节点，旧节点需手动隐藏或删除。

平台不持久保存完整订阅链接，只保存用于识别来源的哈希；节点密码加密存储，预览缓存也加密。需要保留原有 `APP_KEY` 才能读取这些密码。管理员节点列表和预览响应不返回密码，用户获取订阅时按所分配的权限组输出机场原始凭据。订阅链接和预览令牌不写入管理审计日志。

## 使用范围

外部节点使用机场账号的固定认证信息，各平台用户共享其额度。平台只能控制后续订阅中是否分发节点，无法按用户统计外部节点流量、强制执行速度／设备限制，或撤销客户端已经保存的连接凭据。套餐到期或节点隐藏后，客户端此前保存的配置仍可能连接成功，直至上游凭据失效。

外部节点不绑定机器、不启用平台节点后端，也不参与节点用户同步。平台收不到其心跳，因此现有列表的离线状态不代表机场节点不可用。实际可用性以客户端连接测试为准。

## 管理 API

接口位于 `/api/v2/{后台安全路径}/server/manage`，均要求管理员认证。

- `POST /previewSubscription`：传入 `subscription_url`，返回 `preview_token`、安全的节点摘要（`key/name/type/host/port`）与 `skipped`。
- `POST /importSubscription`：传入 `preview_token`、选中节点的 `node_keys` 数组、`group_ids` 数组和布尔值 `show`，返回 `created` 与 `updated` 数量。导入使用预览时的内容，不会重新下载。

导入操作在事务内完成；同一来源并发导入会加锁，数据库唯一键用于防止重复节点。
