# 节点高级筛选

节点管理表格上方提供高级筛选，多个条件取交集：

- 名称、地址、节点 ID：不区分大小写的包含搜索。
- 显隐：显示或隐藏。
- 来源：订阅导入或自建节点。
- 心跳状态：在线且有推送、在线未推送、离线、外部订阅无心跳数据。前三项只匹配自建节点，不以心跳判断机场节点可用性。
- 部署方式：独立部署、机器托管已启用、机器托管已停用。
- 标签：包含指定文字。
- 连接端口：精确端口；节点使用端口范围时，匹配包含该端口的节点。
- 倍率、在线人数：包含边界的最小值/最大值，允许只填一端，支持 0。

点击“应用筛选”刷新列表并清除旧选择，在当前浏览器标签页保留高级条件。随后可使用原有类型、服务器、权限组筛选继续缩小范围，勾选和批量操作使用当前结果。“清空高级筛选”恢复高级条件的全部范围。

倍率条件使用节点配置的基础倍率；在线人数使用平台接收的上报，外部订阅通常为 0，不能代表机场实际人数。

后台前端为上游编译产物，因此通过独立资源扩展筛选表单，未修改编译 bundle。请求适配仅作用于当前节点管理页的 GET `server/manage/getNodes`，携带 `node_filter[...]`；服务端校验后过滤列表，保持原有响应数组结构与顺序。其他接口及客户端订阅不受影响。

## 多维分组与批量分类

可按协议、地区、管理分组、运营商/机场、订阅来源、传输方式、标签浏览分组数量。协议可多选，SS2022 与普通 SS、Hysteria 1 与 2 分开。点击分组卡片切换条件；“全部分组”只清除此维度的条件，保留其他维度。当前维度的分组计数会忽略该维度自身条件，以便切换同级分组。标签维度允许一个节点计入多个标签。

地区支持 249 个 ISO 国家/地区。默认先识别名称中的国旗，再用名称/标签中的常见地区或城市词推测；无法识别时进入“未识别地区”。此结果不是 IP 地理位置核验。批量分类可人工覆盖地区，也可清除人工覆盖恢复自动识别。

管理分组（例如“亚洲专线”）和运营商/机场字段供管理人员分类，不改变权限组与用户可见范围，不包含在用户订阅中。相同链接导入的节点会按订阅来源聚合；来源显示匿名编号，不保存或暴露订阅 URL。可用运营商/机场字段补充易读名称。

点击“批量分类当前结果”，窗口重新获取当前高级筛选结果，初始不选任何节点。可以单独勾选或明确全选后，批量设置地区、管理分组、运营商/机场，以及追加/移除标签。只有勾选启用的字段会修改，留空表示清除此字段；追加/移除标签保留其他标签。单次最多 5000 个节点，保存使用事务；订阅重新导入保留人工分类。

批量分类范围使用本面板已应用的高级筛选条件，不读取上方原有类型/服务器/权限组控件或表格勾选。窗口列出明确的目标节点，请按窗口勾选确认。需要按协议分类时使用本面板的协议多选。

常用视图可保存最多 20 组高级条件和分组维度，保存在当前浏览器本地，非跨设备同步。重复名称覆盖同名视图。

升级需要执行数据库迁移 `2026_10_28_000002_add_node_management_dimensions`。新增管理接口均受管理员鉴权保护：`GET /dimensions` 与 `POST /batchClassify`，路径与原节点管理接口相同。

连通性检查入口与结果含义见[节点连通性测试](./node-probe.md)。
