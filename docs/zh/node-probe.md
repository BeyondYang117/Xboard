# 节点连通性测试

在节点管理的“节点多维管理”面板中，先按协议、地区等条件缩小范围，点击“测试连通性”，勾选节点后开始。单次最多 200 个节点，浏览器同时派发 2 个请求，服务端最多允许 4 个测试并行。同一节点不能同时重复测试。

## 两种测试

- **TCP 端口连接**：验证面板服务器能否建立 TCP 连接，显示连接耗时。端口开放不代表代理认证、TLS 或转发可用。UDP/QUIC 协议显示不支持 TCP 判断，需使用代理实测。
- **代理实测**：生成独立 sing-box 出站配置，使用节点真实认证信息，经节点请求指定 HTTPS 测试网站。仅 HTTP 204 判定成功，不跟随重定向，不使用直连回退。显示完整请求耗时、时间、测试目标和失败阶段。

测试网站为 Cloudflare 或 Google 的固定 `generate_204` 地址，API 不接受任意 URL。若一个网站不可达，可以换站重测。结果仅代表测试时面板服务器的网络情况，并非用户设备的连接情况，也不是带宽测速。

节点使用端口范围时仅测试首个端口。测试地址必须是公网地址；私网、回环、保留地址及混有这些地址的 DNS 结果会跳过。解析通过后固定实际拨号 IP，保留 TLS SNI 和传输 Host。

## 认证账号与协议

外部订阅直接使用已加密保存的上游密码/UUID，无需指定平台用户。自建节点的代理实测需要填写测试用户 ID；此用户必须未停用、未到期、有剩余额度，且属于节点权限组。测试不创建用户，不修改用户或节点配置，但会消耗上游或测试账号少量流量。

代理实测复用客户端订阅的出站构建逻辑，支持 SS/SS2022、VMess、VLESS、Trojan、Hysteria 1/2、TUIC 5、AnyTLS、SOCKS、HTTP 及内核接受的 TCP/WS/gRPC/H2/HTTPUpgrade 等配置。Naive、Mieru、TUIC 4、依赖外部插件或内核无法接受的参数会明确显示“不支持”，不能据此判定节点不可用。

## 结果与运行环境

成功、网络失败、配置不支持、缺少账号/测试内核分别显示。可“选择失败项”重新测试；“停止后续测试”停止派发新任务，正在执行的任务完成后结束。HTTP 请求超时 8 秒，TCP 最多约 4 秒；DNS、内核启动和配置校验另有开销。

最近一次成功或网络失败结果在共享缓存中保留 30 分钟，TCP 与代理实测分别保存。节点连接配置或上游凭据变化后旧结果不再显示；结果不会替代节点心跳。测试账户状态后续变化时，应重新测试确认。

新版 Dockerfile 包含官方 sing-box 1.14.4，并固定上游多架构镜像摘要。源码部署需自行提供可执行的 sing-box，可用 `NODE_PROBE_BINARY` 设置路径，默认 `/usr/local/bin/sing-box`。缺少内核时仍可 TCP 测试，代理实测显示环境错误。

测试仅监听回环地址上的随机端口并使用随机本地认证。临时配置文件权限为 0600，正常完成或捕获到异常后清理；内核输出不会返回界面或写入应用日志。网站 TLS 证书校验始终开启；上游节点 TLS 设置沿用节点配置。

管理 API 均要求管理员认证，前缀 `/api/v2/{后台安全路径}/server/manage`：

- `POST /probeHistory`：`ids`（最多 200 个），返回最近结果、可选目标和内核可用状态。
- `POST /probe`：`id`、`mode`（`tcp`/`proxy`）、`target`（`cloudflare`/`google`）、可选 `user_id`。结果包括 `state`、`stage`、`latency_ms`、`tested_at`，不包含凭据。
